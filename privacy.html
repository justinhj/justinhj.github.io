Privacy and Security Information

This site runs over a secure connection only. In order to track which content is popular I use Cloudflare Web Analytics. Read on if you wish to know more.

1. Secure Connection (HTTPS)

This website is served entirely over HTTPS. This means the connection between your browser and the servers hosting this site is fully encrypted.

  • Protection from Snooping: Your internet service provider, or anyone else on your network, cannot intercept or manipulate the data you are viewing on this site.
  • Integrity: HTTPS ensures that the pages you receive are exactly what I published, without any unauthorized modifications or injected advertisements along the way.

2. Analytics and Performance Tracking

To evaluate site performance, diagnose page load regressions, and understand aggregate traffic patterns, I use Cloudflare Web Analytics. This service focuses strictly on performance telemetry and real-user monitoring without compromising your privacy.

  • No Cookies or Local Storage: Cloudflare Analytics sets no persistent cookies and does not access browser storage to track you across sessions or across other websites.
  • No Personal Data or URL Query Strings: The browser script automatically strips out all URL query parameters (e.g., ?query=...), hash fragments, and embedded authentication details before data is sent, preventing sensitive tokens or search queries from ever being logged.
  • System & Device Context: The script collects high-level technical telemetry: normalized operating system version, browser rendering engine (e.g., Blink, Gecko, WebKit), and general device family.
  • Core Web Vitals & Performance: Standard browser performance APIs track load times (TTFB, FCP), layout stability (CLS), user interaction latency (INP), and asset render timings (LCP). To identify rendering bottlenecks, the script may log CSS selectors or DOM IDs associated with elements that shift or delay paints.
  • Session Isolation: Each visit generates a temporary, random identifier (pageloadId) purely to associate related performance events during a single view or client-side route navigation. It is not tied to your identity.
  • IP Address & Country-Level Metrics: The script does not access browser geolocation APIs. Approximate geographic data (country level) is inferred server-side by Cloudflare upon receiving the payload. Raw IP addresses are discarded and are neither exposed nor stored in reporting dashboards.
  • Opting Out: Because this telemetry runs via a client-side JavaScript beacon, you can disable it at any time using common content-blocking tools (such as uBlock Origin) or by disabling JavaScript in your browser settings.
