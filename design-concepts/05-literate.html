Refreshing your Neovim config for 0.12.0

*

Introduction

▼

Neovim version 0.12.1 was just released and you can check the release news here at the official documentation. This is a massive release bringing a number of core capabilities that used to require external plugins directly into Neovim as first-class, built-in features.

I took this opportunity to do a full refresh of my config. This was required as over the last few years I had pulled in many plugins only to forget what they are for. My config had accumulated too many files, creating far too much surface area when trying to make changes or fix daily annoyances.

Rather than use an off-the-shelf config distribution, I had built it all by hand to meet my needs perfectly, but without careful maintenance it becomes an overgrown garden. In particular, my LSP configurations and key mappings were scattered in different places, accompanied by cruft I wasn't even using.

*

Running two configs on the same machine

▼

It is immensely easier to develop a new configuration if you keep your existing one readily available for reference, allowing you to run the new and the old side-by-side. The key to making this work seamlessly is the NVIM_APPNAME environment variable.

Normally Neovim expects the various configuration folders to reside in ~/.config/nvim. By using NVIM_APPNAME, you can point to a secondary identity—I chose nvim-next. This lets you construct an entirely new config while leaving your daily driver completely untouched.

#+BEGIN_SRC bash :tangle ~/.setup.sh 
mkdir -p ~/.config/nvim-next
mkdir -p ~/.local/share/nvim-next
mkdir -p ~/.local/state/nvim-next
mkdir -p ~/.cache/nvim-next

With folders in place, you can launch the isolated instance immediately:

#+BEGIN_SRC bash 
NVIM_APPNAME=nvim-next nvim

Replicating the config

▼

I needed a structured method to migrate options without overlooking critical behaviors. I began with the essential editor settings in init.lua:

#+BEGIN_SRC lua :file init.lua 
vim.g.mapleader = ","
vim.opt.shortmess:append("c")
vim.opt.cmdheight = 2
vim.opt.number = true
vim.opt.relativenumber = true
vim.opt.timeoutlen = 500
vim.opt.ignorecase = true
vim.opt.smartcase = true
